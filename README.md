One line under 200 characters: the most creative excuse a hardware wallet
gives for refusing to sign a transaction at 3 AM. Entry for the
[make.fun](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878)
bounty "The 3 AM Excuse".

## Entry

> It's 3 AM — my private keys voted to strike. No signatures until sunrise, and the picket line is encrypted.

107 characters, one line.

## Run

```sh
node main.ts   # Node 22 — writes the entry to /output/entry.txt
```

`main.ts` self-checks the gate (1–200 characters, one line, not blank) and
verifies the file byte-for-byte on read-back.
